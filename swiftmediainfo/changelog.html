SwiftMediaInfo v2.1

23 October 2026 On GitHub

SwiftMediaInfo v2.1 – Latest Release

Tabs, a rebuilt Compare Mode, Media Health, previews with Space, and Siri AI — and the whole app made faster and lighter without changing how it looks

The biggest update since 2.0. Files open in tabs now, comparing two of them takes one click, and the app can tell you what a file is, whether anything is wrong with it, and show it to you — MKV included.

Website · What's in it · Field reference · FAQ · Full changelog

⭐ Highlights

🗂 TabsEvery file in its own tab, Safari-style — and a folder as one tab, with its media files beside the report
⚖️ Compare Mode, rebuilt around tabsFile A and File B are just two of your open tabs. ⌘-click any tab to compare
🔎 An Overview of every fileVideo, main audio and subtitles at a glance, with colour-coded highlights
🩺 Media HealthOne click (⇧⌘H) checks a file for common problems and explains what to do about each one
▶️ Preview with SpaceQuick Look for what macOS can play, and a new preview for MKV and everything it can't — every subtitle track included
✨ Siri AIAsk what a file is, whether it is healthy, or which of two copies is better — answered on your Mac
📄 PDF and Markdown reportsA designed PDF, and Markdown ready for the pastebin of your choice
⚡ Faster and lighterA steady smooth scroll, using less of the GPU, CPU and memory — with the same look

🌐 New on the website

undisclosed0369.app/swiftmediainfo is up to date for 2.1, with new screenshots throughout.

  • Open in SwiftMediaInfo — read a file on the Online page, then open the same file in the app with one button. The page never learns where the file is; it sends the app the file's name, size and date, and the app finds it on your Mac
  • Try in Browser — for a quick look on a computer without the app. One file, nothing to install, and the file never leaves your browser
  • Install in one command with Homebrew, plus how to update and the current macOS steps for the disk image
  • Addresses are shorter and forgiving: no .html at the end, and any capitalisation lands on the right page

🆕 New

🗂 Tabs

Every open file lives in a tab, and the tab bar is always there.

  • New Tab (⌘T) opens an empty tab with the start screen; opening a file fills it
  • Drag to reorder, or drag a tab out onto the Dock or another app to open the original file there
  • Long names scroll on the selected, hovered or compared tab; the others are shortened in the middle
  • A tab menu with Close Tab, Close Tabs to the Right/Left, Close Other Tabs, New Tab to the Right, Compare With and Add to Favorites
  • The + button: click for a New Tab, right-click for Favorites, Recent Files and Choose a File…
  • Middle-click a tab to close it, or a recent file to open it in a background tab
  • Opening a file that is already open switches to its tab instead of opening it twice
  • The tab you are looking at loads first; the others load in the background

📁 Folder tabs

  • Drop or open a folder to get one tab named after it, with a sidebar of its media files — subfolders included
  • Only the file you select is analysed. Step through them with ⌥⌘↓ / ⌥⌘↑

📥 Opening files

  • Drag-and-drop that does what you mean — onto the window, the panes or the Dock icon: one file opens a tab, two open a comparison, three or more open a tab each, a folder opens a folder tab
  • The Open dialog accepts several files and folders at once
  • Finder gains "Open Folder in SwiftMediaInfo", "Open N Items in SwiftMediaInfo", and opening the folder you are viewing by right-clicking empty space
  • The Finder menu switches itself on the first time the app opens — no trip to System Settings. Turn it off in Settings › General › Finder (or System Settings) and it stays off
  • From the website — Open in SwiftMediaInfo on the Online page opens the same file in the app, found with Spotlight and in the folders you have opened files from, external and network drives included

⚖️ Compare Mode

Rebuilt around tabs, so comparing never re-reads a file.

  • File A is the selected tab and File B is another open tab
  • Compare by ⌘-clicking a tab, by right-clicking → Compare With (open tabs, favorites, recent files, or a file), or with the Compare button
  • Blue "A" and pink "B" badges and outlines on the tabs, matching the panes and the status bar
  • Close either side from its pane header; an empty pane offers your open tabs, favorites and recent files
  • Click File B's tab to swap the sides

⭐ Favorites

  • A star on every tab
  • File › Favorites to open one, compare it with the current file, remove it, or clear them all
  • Favorites appear on the start screen above Recent Files, and wherever you pick a file to compare
  • Folders can be favorites, renamed files keep their star, and missing files are marked
  • Long lists in menus show the first five, with the rest under "N More"

🏠 The start screen

  • Total time spent in the app — counted only while it is in front and in use, and carried over across updates
  • 50 fun facts about that time, rotating every 14 seconds, with ← / → to flip through them
  • Favorites, Recent Files and the time card can each be hidden in Settings › Privacy

🔎 Easy View

  • An Overview card at the top of every report:
  • Video — codec with profile, level and tier, resolution, frame rate, bit rate and bit depth, colour and HDR
  • Main audio — language, codec, channels (2.0 (Stereo), 5.1…), sampling, bit rate and track count
  • Subtitles — every track as "Title (Format)", and a summary such as "46 PGS, 11 SRT"
  • Audio files get Audio and Tags; images get an Image block
  • Colour-coded highlight chips — video blue, audio violet, subtitles green, images teal — that stay visible when the card is folded
  • Right-click to Copy Overview, or Copy Overview as Markdown
  • Copy Track as Markdown, in Easy View and in Compare
  • HDR Format is one combined row, e.g. "Dolby Vision Profile 8.1 / HDR10+ Profile B, HDR10 Compatible"
  • Chapters read as a clean list — "00:02:09.379 — Ground Zero"

🩺 Media Health (⇧⌘H)

  • Checks that the container is readable and complete, that the format matches (including an extension that does not match the contents), the video and audio streams, unique track IDs, variable frame rate, HDR metadata, language tags, and that video and audio durations agree
  • A plain verdict — "This file looks healthy" or "3 things to look at" — every check marked ✓ / ⚠ / –, and what each problem means and what to do about it
  • Knows what is normal: a song without video, or an untagged music file, is not flagged
  • Copy the report as text or Markdown. In Compare Mode, switch between File A and File B

▶️ Preview with Space

Space previews the current file, as in Finder. Space or Escape closes it.

  • Files macOS can play open in Quick Look, which follows you as you switch tabs
  • MKV, AVI, WebM, TS, MKA and the rest open in the new SwiftMediaInfo preview:
  • 20-second clips cut from the original and played by macOS's own player — 4K, HDR and Dolby Vision included. Audio macOS cannot play, such as DTS and TrueHD, is converted to stereo for the preview
  • Every subtitle track. Text subtitles play in macOS's player; picture subtitles — Blu-ray PGS, DVD, DVB — are drawn over the video exactly as on the disc, in full screen too. Your choice is remembered for each file
  • Files without subtitles can show subtitles transcribed by macOS from the clip's speech (macOS 27)
  • A filmstrip timeline of the whole file — hover for a time, click or drag to play from anywhere
  • ±10 s buttons, or ← / →, and Open with your default player from the title bar
  • Volume, mute, speed and zoom are remembered from clip to clip, file to file and launch to launch
  • The window opens at the shape of the video, so the whole picture fits with no extra black
  • Your file is never changed. Temporary clips are deleted as you go and the moment the preview closes
  • The SwiftMediaInfo preview uses ffmpeg, which is optional. If it is missing, the app installs it in one click

✨ Siri AI

  • Ask Siri in the toolbar, File › Ask Siri AI… (⇧⌘I) or File Actions
  • It starts with "Can you tell me what this is?", answers from the file's report, and takes follow-up questions — with suggestions such as "Explain in simple terms"
  • Ask about health and it uses Media Health's own results; ask for an overview and it uses the app's Overview
  • In Compare Mode it compares File A and File B and says which is the better copy
  • Stop an answer with the Stop button or Esc, and ⌘R asks a stopped question again
  • On-device only. It reads MediaInfo's text report — never the file — with file paths removed, and nothing leaves your Mac
  • Needs a Mac that supports Apple Intelligence, running macOS 27 or later, with Apple Intelligence turned on. Elsewhere it stays out of the way, and Settings › Siri AI explains why

📄 Export and share

  • PDF (new) — an A4 report with the overview, colour-coded highlights, a table for every track, and clickable links. Real text, selectable and searchable
  • Markdown (new) — headings, the Overview, a table per track and a chapter table, ready for the pastebin of your choice
  • The Export menu is grouped into Human-readable (Text, Raw Text, HTML, PDF, Markdown) and Machine-readable (CSV, JSON, XML), plus Export All Formats and Export All as ZIP
  • HTML exports now look exactly like the in-app HTML view, and HTML and PDF follow the app's light or dark appearance
  • Share as a web page — HTML and PDF become a page on ship.page, Markdown a rendered page on markdown.page; text formats go to pb.plz.ac and ZIP to up.sb
  • The review screen before every upload shows what will be removed, and whether the SHA-256 checksum is included

🎨 Code views

  • Syntax highlighting for JSON and XML, in a restrained Xcode-style palette that reads well in light and dark — on in Compare and while searching too
  • Settings › Appearance › Code Views: On, Off, Only JSON or Only XML

🎛 Settings

  • A new Siri AI pane
  • MediaInfo is now Tools, with sections for MediaInfo and ffmpeg — status, location, and install or reinstall
  • Overview: Remember Last, Always Expanded or Always Collapsed
  • Blob positions — with the Static background, drag the three colours to where you want them
  • Privacy › Include paths in HTML and Include the SHA-256 checksum — Always, Ask or Never (default)
  • Privacy › Empty Screen — show or hide Favorites, Recent Files and the time card
  • Media Health › Include SHA-256 availability, for files over 10 GB
  • General › Finder › Right-click menu — the same switch as in System Settings
  • Restore Defaults also resets the preview's volume, speed, zoom and subtitle choices, and turns the Finder menu back on

🔒 Privacy

  • Two new settings, both Never by default: Include paths in HTML and Include the SHA-256 checksum — each Always, Ask or Never

🐞 Fixed

  • A crash when an analysis was cancelled at the moment it started
  • Compare Mode showing every field as "only in File A" while File B was still loading
  • ⌘W closing the window — and quitting — instead of the tab
  • Easy View showing a blank screen for folders
  • Empty exports for views that had not loaded yet, and Text exports saved as ".text" instead of ".txt"
  • The privacy filter could rewrite the app's own website link when your account name was part of the domain
  • Export and Share dialogs opening while their menu was still closing, flooding the log with "Publishing changes from within view updates" warnings
  • ⌘M minimised the window with Media Health, Share or the preview open
  • New users had to switch the Finder menu on in System Settings themselves, and switching it off was undone the next time the app opened
  • The Keyboard Shortcuts window showed Control (⌃) instead of Option (⌥) for Close Window, Copy Path and the folder-tab keys
  • The back button in Compare Mode's Share and Export menus was almost invisible

⬆️ Upgrading from 2.0

Nothing to do. Your settings and the time you have spent in the app carry over.

  • With Homebrew: brew upgrade --cask swiftmediainfo
  • With the disk image: download it below and replace the copy in Applications. macOS checks the new copy once, as it did the first time — the download page has the steps
  • ffmpeg is new and optional. It is only needed to preview MKV and other formats macOS cannot play, and the app offers to install it the first time you need it

📋 Requirements

  • macOS 26 or later
  • The MediaInfo command-line tool — installed from within the app, or from MediaArea
  • Optional: ffmpeg, for previewing MKV and other formats macOS cannot play — also installed from within the app
  • Siri AI: a Mac that supports Apple Intelligence, running macOS 27 or later, with Apple Intelligence turned on

🙏 Built on MediaInfo

Every number this app shows you was read by MediaInfo, a separate project by MediaArea, maintained for two decades. They wrote the hard part. This is the window onto it. The new previews are cut and converted by FFmpeg, the open-source project behind a great deal of the world's video software.

If you need Windows, Linux, a language other than English, or a signed application, MediaArea's Mac app is the better choice and you should use it.

SwiftMediaInfo v2.0

Rebuilt from the engine up — settings, checksums, plain-language explanations, and an accessibility pass that reaches every control

The largest release since the app began. Almost every file was rewritten, and the parts you can see are the smaller half of it.

Website · What's in it · Field reference · FAQ · Full changelog

⭐ Highlights

🎛 A real settings windowSix panes. Everything the app used to decide for you is now yours to set
🔒 SHA-256 checksumsComputed on request, cached, and carried into exports
📖 Around 70 fields explainedPlain language, inline, for the ones nobody remembers
🎨 A background you ownThree modes, colours you pick, four ready-made palettes
♿ Full VoiceOver supportBuilt into the shared components rather than bolted on
🧱 A custom design systemSpacing, motion and colour defined once, on macOS 26's Liquid Glass

🌐 The app has a website now

undisclosed0369.app/swiftmediainfo

Everything that used to live in a README now has room to breathe: what the app does, how it compares to MediaArea's own Mac app including the things theirs does better, what the first-launch warning actually means, what leaves your machine and when, and a changelog that updates itself from these releases.

The app links to it too — ⌘/ opens it, and so does the Help menu.

It sits on undisclosed0369.app, which is where anything else I put out will live.

📚 Field reference

The complete field reference →

Every field the app can explain, written out in one document — what it means, why it is there, and what a normal value looks like. The app shows these inline as you read a report; this is the same material in one place, for when you would rather have it all at once or want to read ahead.

🆕 New

🎛 The settings window

The app had no settings window before. It has six panes now.

  • General, Appearance, Analysis, MediaInfo, Privacy and Advanced
  • Interface scaling — zooms the whole settings layout, not just the text in it
  • Restore Defaults, returning every preference at once
  • Copy environment summary for bug reports: version, macOS, architecture, MediaInfo path and version, and your current settings
  • MediaInfo installation moved here from the bottom bar, with four honest states — checking, missing, installing, failed — and a Retry that genuinely retries
  • Re-detect, for straight after installing or upgrading MediaInfo

🔒 Verification

  • SHA-256 checksums for any open file, included in exported reports — so an archive copy can be checked against the original years later
  • Real progress while hashing, and cancelling stops the work immediately rather than only hiding it
  • Results are cached, so the same file is never hashed twice
  • Computed on request rather than automatically, because hashing means reading every byte of the file

📖 Reading

  • Plain-language explanations for around 70 fields, inline — for anyone who has wondered what a chroma subsampling ratio actually is. The whole set is also written out as a field reference
  • Copy any single value, or a field and its value together, from a hover affordance or the context menu

🎨 The background

1.6 had an animated background you could toggle. It is now something you own.

  • Three modes — Off, Static and Animated
  • Custom colours — three shades, with colour wells and hex fields
  • Four palettes — Signature, Tide, Meadow and Ember
  • A Liquid Glass toggle, for anyone who would rather have solid surfaces and the battery life that comes with them

📂 Files

  • Five file actions from one menu: reveal in Finder, copy path, open in the default app, rename, and move to Trash

🛡 Privacy

  • Review before sharing. A report is shown in full before it is uploaded, with the option to strip file paths first — a path often carries a username, and sometimes a good deal more

🔗 Links out

  • Website links in the About window, the Help menu, and at ⌘/ — which now opens the website rather than GitHub
  • Frequently Asked Questions in the Help menu, going straight to the page that answers the common ones
  • Double-clicking the app icon in Settings opens the website
  • A Donate button in the About and Settings windows, for anyone who wants to say thanks. Everything is free and stays free — nothing is locked, and nothing changes in the app either way

⚡ Improved

🛠 Finder integration

The extension existed. It now works properly.

  • Works in every folder, not only some
  • Select two files and compare them directly from the Finder menu

⚖️ Comparison

  • Differences are computed once and symmetrically, so the two sides can never disagree about what changed
  • A summary panel lists every difference, and clicking one jumps straight to that field
  • Swap the two sides from a control on the divider
  • Hold ⌥ while dragging a second file onto an open one to compare without leaving the window

💬 The About and Shortcuts windows

Both existed. Both were rebuilt.

  • Redesigned on Liquid Glass to match the rest of the app
  • The shortcuts reference gains new entries and notes where a shortcut applies only to a single open file
  • Escape closes both, and ⌘M no longer minimises the About window — which had no business being minimisable

🚀 Performance

  • The animated background is rendered at quarter resolution and scaled up. It is a soft gradient; nothing is lost, and it costs a fraction as much to draw
  • It now also pauses in Low Power Mode, on top of the scroll, occlusion and background pausing from 1.6
  • Row hover is instant. Sweeping the pointer down a list used to start dozens of overlapping animations at once
  • Analysis results are cached, so reopening a file is immediate
  • A full pass over the codebase: dead code removed, duplicated logic consolidated, and a number of smaller efficiency improvements throughout

🧩 Reliability

  • The engine was rewritten with typed errors and safe cancellation. One format failing no longer takes the others down with it
  • Every interface state is named rather than inferred from whether a string happened to be empty
  • The default analysis timeout is 60 seconds — long enough for any real file, short enough that a hang does not feel like a freeze

♿ Accessibility

A full pass, made at the shared components so it applies everywhere rather than being added screen by screen.

  • VoiceOver throughout, with meaningful labels, hints and states on every control
  • Reduce Motion and Reduce Transparency honoured at the design-token level
  • Complete keyboard control

🔧 Under the hood

Not user-facing, but it is why the rest of this list was possible.

  • A design-token system — spacing, radii, elevation, motion and colour, defined once and used everywhere
  • Accessibility helpers built into the shared components, so a new control inherits correct behaviour instead of needing it added
  • Export logic moved to its own file; MediaStore shrank by about 750 lines
  • Every external address lives in one place, so a link can no longer rot in three files at once
  • Dead code removed, including several helpers nothing called any more

⬆️ Upgrading from 1.6

Two one-time things, both expected:

  • Your settings return to defaults. The app's internal identifier changed in this release, so macOS looks for preferences under a new name and finds none. Nothing is lost from your files — the old preferences are simply ignored. Set your appearance and background once more and it will stick.
  • The Finder extension may need re-enabling. For the same reason, macOS treats it as new. The app re-enables it on launch, but if the right-click menu is missing, look in System Settings → General → Login Items & Extensions → Finder Extensions.

SwiftMediaInfo v1.6

Online Sharing, Powerful Search, & Visual Compare Update

SwiftMediaInfo v1.6 is the biggest feature update yet! This release introduces direct online sharing, a powerful new search engine with fuzzy matching, visual difference highlighting for file comparison, a fully rewritten HTML engine, and minor performance optimizations for large media files.

✨ New Features & Improvements

🌐 Online Sharing & Instant Uploads

  • Share Online Support: Easily upload media metadata directly to web paste services right from the app!
  • Single files can be uploaded to pb.plz.ac (TXT, Raw Text, CSV, JSON, HTML).
  • Multi-format bundles export to up.sb as a ZIP.
  • In Compare Mode, choose which file to share. All uploads run securely in the background via curl with temporary files automatically purged after upload.
  • Polished Upload Result Sheet: View your generated link in a native sheet with a one-click Copy Link button (featuring a "Copied!" confirmation badge) and direct browser launching.

⚖️ Difference Highlighting in Compare Mode (⌘D)

  • Color-Coded Compare Analysis: Pressing ⌘D instantly highlights differences between two files:
  • 🧡 Orange: Modified / differing values.
  • 💙 Blue: Fields unique to File A.
  • 🩷 Pink: Fields unique to File B.
  • Per-Track Difference Badges: Track cards display badge counts showing exactly how many differences exist per track.
  • Works across Easy View (per field), Text View, and Raw Text View (per line).

🔍 Floating Search Engine & Fuzzy Matching

  • Universal Search Bar (⌘F): A floating, non-intrusive search bar that works seamlessly across all view modes (Easy, Text, Raw Text, HTML, and Compare).
  • Features real-time match counters and up/down navigation controls.
  • Full keyboard support (Enter for next, Escape to close, arrow keys for navigation).
  • Smart Fuzzy Search: Searching for terms like "bitrate" automatically matches "Bit Rate", "framerate" finds "Frame Rate", and more.
  • Search + Difference Layering: Search highlights (green) layer intelligently on top of difference highlights in Compare Mode without breaking visual context.

🌐 Complete HTML View Engine Rewrite

  • WebKit Engine Integration: Replaced NSTextView rendering with WKWebView for pixel-perfect CSS tables, rounded borders, alternating row stripes, custom scrollbars, and hover effects.
  • Smooth CSS Zooming: Changing font zoom levels applies dynamically via lightweight JavaScript calls without triggering full page reloads.
  • Native Injected Search Highlights: Custom JavaScript highlights search matches with active outline rings in real time.

🖥️ UI, Workflow & Navigation Improvements

  • Interactive Keyboard Shortcuts Window (⌘K): A beautiful reference window showcasing all shortcuts grouped by section (File, View Modes, Display, Compare, Tools, Help) with custom key badges and alternating shading.
  • Split Status Bar in Compare Mode: The bottom status bar splits down the center divider, displaying File A's metadata on the left and File B's on the right simultaneously.
  • Marquee Filename Scrolling: Long filenames in Compare Mode headers scroll smoothly in a loop with natural pauses at each boundary.
  • Capsule Pill Zoom Badge: Redesigned the toolbar zoom indicator into a sleek pill badge with a blue-to-violet gradient flash upon size changes.
  • New Global Keyboard Shortcuts:
  • ⌘B – Toggle Animated Background
  • ⌘D – Toggle Difference Highlighting
  • ⌘F – Global Search
  • ⌘K – Open Keyboard Shortcuts Reference
  • ⌘M – Cycle Appearance (Light → Dark → System)
  • ⌘0 – Reset Zoom to 100%

🛠 Dependencies & Diagnostic Checks

  • Automatic System Diagnostic Check: SwiftMediaInfo checks for mediainfo, curl, and zip on launch.
  • Offers one-click Homebrew package installation for missing dependencies.
  • Provides an Install CLI Tools button (xcode-select --install) for missing system tools.

🚀 Performance & Optimization

  • Zero-Waste Animation Engine: The animated background now intelligently pauses during scroll gestures, window occlusion/minimization, or when the app is in the background—reserving zero GPU overhead when out of view.
